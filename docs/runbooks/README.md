# Runbooks

Trail v1.1 runbooks are operational contracts for incidents that affect user trust, privacy, provider reliability, and account access.

## Available runbooks

- [Incident response](incident-response.md)
- [Data deletion incident](deletion-incident.md)
- [AI provider outage](provider-outage.md)
- [Authentication incident](auth-incident.md)
- [Tabletop exercise v1](tabletop-exercise-v1.md)

Each runbook must define owners, detection, mitigation, recovery, and verification before it is considered release-ready.
